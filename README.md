## 📖 Sobre

O **API EM DIA** é um **aplicativo web** que permite **testar APIs de diversos tipos** de forma **gratuita** e **profissional**. 🧪

A proposta é facilitar o dia a dia de quem desenvolve: enviar requisições, conferir as respostas e validar se a integração está funcionando, tudo direto no navegador, sem precisar instalar nada.
